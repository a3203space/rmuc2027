# 右键按住自瞄设计

## 源码参考

参考项目：[chenjunnn/rm_auto_aim](https://github.com/chenjunnn/rm_auto_aim)，许可为 [MIT](https://github.com/chenjunnn/rm_auto_aim/blob/main/LICENSE)。本次查阅 `armor_tracker/src/tracker.cpp` 和 `tracker_node.cpp`，借鉴准星中心优先选择、固定目标身份、角度连续和搜索/跟踪/丢失状态划分。未移植第三方代码；仿真直接使用受可见性约束的观测与现有 SDK 提前量、弹道计算。

## 数据与控制

- 网页在左右键按下和松开时立即发包；持续输入仍每 20 ms 发送。`fire` 表示左键按住，`fire_press_seq` 是本局单调递增的按下计数，`aim_assist` 表示右键按住。
- 主机在收到包时保存未处理的点按，去重、队列上限 8，每个物理步最多处理一个。点按和按住合并为一次普通 fire 指令，实际发弹由引擎决定，受阻事件不重试积压。失效输入和中断清空点按队列。
- 自瞄候选必须同时属于本席位 `vision.enemies` 和光学敌方观测；队友视野、战术雷达位置不会补充候选。
- 获取范围为相机准星中心 15°，保持范围为 20°；同一目标有效时优先保持，其他候选按角度及 ID 稳定排序，并检查弹道可达。
- 调用 SDK `intercept`、`aim_at`、`aim_pitch`，生成普通 aim/pitch，不产生 fire。物理引擎保留云台速度与角度限制。
- 松开右键或目标丢失时以实际云台角度接续手动输入，再应用客户端角度的差值；yaw 差值用最短角距离，避免跨越 ±π 跳变。辅助只控制云台，底盘继续按手动方向驾驶。
- HUD 的自瞄状态与目标 ID 只下发给该玩家。右键松开立即更新本地指示，主机在下一个物理步停止跟踪；传输失效 250 ms 内停止人工控制。
- Rust `fire_block_reason_2027` 同时用于实际开火和快照武器状态，涵盖弹药、堡垒储备、冷却、热锁、发射机构、装配、变形与机器人状态。网页展示主机翻译后的原因。

## 生命周期

菜单、失焦、指针捕获丢失、断线、战亡、过热或判罚遮挡会清空射击和自瞄。重连恢复控制、下一局开始均不会重放旧点按。首次点击画面只捕获鼠标，提示后再点击或按住左键射击。
