2. **全真物理下前插压制与生存兼具**：在 6 局获胜对局中，哨兵稳定活跃于中央区与蓝方前哨/中央点（对 `hunter` 占据 `blue_central` 达 `41.1s` 并打出 `732.7 : 14.9` 控制比；对 `pressure` 占据 `blue_central` `25.3s` 并打出 `605.5 : 19.4`），同时达成 **6 局零阵亡、全 8 局 0 次 `stall >= 4s`**。
3. **残余两处可继续打磨点**：
   - `dsv41_1017_pair`（`1018`）：敌方双核心高效率抢占两处点位形成 `1088` 控制分，单哨兵难以同时对抗双线刷分，第 `356.9s` 在深入敌方蓝路 `(22.53, 1.2)` 时阵亡 1 次；
   - `gemini38_2027_tech_overload`（`1000`）：敌方高压前推下本局哨兵平均活动区域偏保守（`mean_xy = (8.7, 12.0)`、`pos_ctrl = 0.0s`），未能有效反打中央点。
