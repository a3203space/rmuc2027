# 简化 CUDA 后端验收清单

此清单保留训练目标的完整范围。局部测试或单局速度通过不代表后端已完成。

| 要求 | 当前证据 | 尚需完成 |
|---|---|---|
| CUDA 运动、2 Hz 学习接口 | CUDA 集成测试；RL 重置、同种子复现及故障清理通过 | 各角色完整 RL 回合和实际梯度训练 |
| 原战斗规则 | 射击时钟、弹药/热量/冷却对照；无遮挡命中、柱座遮挡正反例通过 | 多场景与完整迁移对照 |
| 三类阵容每环境至少 5 倍实时 | 原矩阵 8/9 通过；原失败混合种子 7 优化后复测 5.35 倍，摘要不变 | 当前版本全矩阵复测；每项完整 420 秒不超过 84 秒，保留原失败 |
| 多种底盘与组合 | 单底盘双向通行回归；双过洞三个种子基础门槛通过 | 全矩阵、轮腿重装变体、非对称阵容及重生后轨迹 |
| 合理运动与接触 | 墙体扫掠、滑动、重叠恢复、过洞、登阶中断、死亡/断电下落通过局部测试 | 更复杂拥挤、堆叠及落到机器人顶部 |
| 几何与能耗 | 修复坡脊及不规则平台倒角碰撞高度；42,000 点审计保留 5 个精确停机坪边界差异及邻点证据；共享电池/电容、折叠半速和起伏功率规则 | 边界语义；重新校准 2 Hz 过洞/起伏、驱动力与接触及机构状态覆盖 |
| PPO 总吞吐 | 随机采样 128 步单环境 6.94 倍、双环境逐环境 5.16 倍；840 步含并行重置 5.005 倍仅刚过门槛，不含 PPO；串行重置 4.87 倍失败保留 | 增加长序列余量；更多环境数验证；10 分钟含 PPO 基准，逐环境与整体吞吐、实际更新次数 |
| 真实物理迁移 | 平面驱动力修复后，五型号各 20 次双向配对均能通过并稳定停留；轮腿重装 2714 通过本次能力时间门槛，其余四型号仍失败 | 继续校准地形接触；其余能力时间差不超过 20%；30 局已训练策略胜率下降不超过 15 个百分点、无重复卡死 |
| 网页查看学习效果 | 未训练 PPO 模型恢复/导出、Rapier 短局及回放校验通过 | 已训练模型的原 Arena 网页完整对局实测 |
| 多角色 | 1/3/4/7 学习接口；重装固定装配前期再接管 | 各角色完整实测；装配前期不采 RL 样本；所有组合训练配置 |
| 持久化备份 | 代码及轻量验证结果通过本地 SSH 备份到 GitHub | 实际新权重的定时远端备份、下载和恢复验证 |
