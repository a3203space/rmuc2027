| CUDA 运动、2 Hz 学习接口 | CUDA 集成测试；RL 重置、同种子复现及故障清理通过 | 各角色完整 RL 回合和实际梯度训练 |
| 原战斗规则 | 射击时钟、弹药/热量/冷却对照；无遮挡命中、柱座遮挡正反例通过 | 多场景与完整迁移对照 |

| 多种底盘与组合 | 单底盘双向通行回归；双过洞三个种子基础门槛通过 | 全矩阵、轮腿重装变体、非对称阵容及重生后轨迹 |
| 合理运动与接触 | 质量加权车车冲量、墙内阻止深入、3/5/10 车自由/顶墙探针及原通行回归通过 | 更复杂拥挤、堆叠及落到机器人顶部 |

| 网页查看学习效果 | 未训练 PPO 模型恢复/导出、Rapier 短局及回放校验通过 | 已训练模型的原 Arena 网页完整对局实测 |
