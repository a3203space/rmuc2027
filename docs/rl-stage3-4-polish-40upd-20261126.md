1. **收敛 `traverse_bumps`（过减速带移动姿态强制）并无条件化低血保底 `bump_emergency_def`**：

2. **新增 `HEAVY_MEMORY_S = 3.0`（近距敌方重型英雄 3 秒视野防抖记忆）**：
   - 在 `state['last_heavy_near_time']` 记录最近一次观测到 8m 内敌方重型英雄（`role == 'heavy'`）的时间戳（并在阵亡复活时自动清空），在 3.0 秒记忆窗内持续维持 `heavy_near = True`，防止敌方英雄因单帧墙角视野遮挡短暂离开 `obs['enemies']` 导致哨兵瞬间误切 `+25%` 易伤的 `attack` 姿态遭 42mm 炮弹秒杀（根治 `seed=1022` 阵亡 #2）。

## 4. 深度取证发现的新根因与下一阶段（第 3.5 阶段）改进方向

本次 40 轮实测与逐帧溯源定位出 **3 项高价值结构性问题**：

1. **【P0 · 导航/地形】红方减速带西端出口 `(4.5..5.2, 13.4)` 跌落绕路陷阱（直接造成 `1008` 阵亡 #1 与 `1022` 阵亡 #1）**：
   - 当残血哨兵在 `recover` 模式从红方减速带（`x=[5.25, 7.65], y=[12.91, 15.0]`）向西驶向补给区 `[1.5, 13.0]` 时，刚出西端（`x ≈ 5.0`）便稍微向南滑落至 `y ≈ 11.6`（墙/高地边缘南侧），随后导航器被迫规划绕大圈路线**掉头向东直冲敌阵（`x = 5.0 → 8.4`）**，最终在仅剩 3 米到家时白白送死（此前 `v3.3` 的 `1013` 阵亡 #2 也发生在完全同一坐标）。
   - **修复思路**：在 `execute_goal` 中把红/蓝减速带航向与侧向限幅保护的西/东出口安全走廊延伸至补给区一侧（或在减速带西端出口段先以 `y >= 13.6` 过渡点引导），确保下带后沿高台直线进补给区，不再向南滑落掉头。
2. **【P0 · 战术/对手针对】揭开 `dsv41_1017_pair`（`0/32`，`-686` 控分）不败真相**：
   - `1013` 逐帧区域归属统计证实：**蓝方整局占据了红方自家基地 `red_base` 长达 `341.2s / 420s`**（白拿近 1,000 控分），而我方 4 个固定规则队友几乎不回防 `red_base`，哨兵均值又停留在中场 `(14–16, 8–9)` 未回清基地。
   - **改进方向**：① 在多对手池中同步提高 `gemini38_2027_blitz` / `hunter` / `tech_overload` 权重（目前 `0–6%` 胜率），② 评估在观测或奖励中加强**己方基地遭敌方偷占时的回防引导/奖励塑形**（或给哨兵更高的位置控制奖励权重并继续在 `latest.zip` 基础上 `--resume` 拉长训练至 100 轮）。
3. **【P1 · 工程加速】消除 `contacts.py` 单线程 4096 次碰撞微震拖尾 + 压缩策略进程 74 KB 静态观测**：
   - 本次 40 轮训练期间观测到第 28 轮附近 `PID 168096`（6 号分片）因多车顶死墙角触发 [contacts.py:90](file:///media/rm/E3E258F427E8E547/rmuc2027/research/rmuc2027_research/rl/warp_kinematic/contacts.py#L90) 单线程 4,096 次零进尺循环，导致全组短时从 `~30 steps/s` 掉到 `~3.3 steps/s`（实测均值被拉低至 `26.92 steps/s`）；后续可通过“连续零进尺微震早停”与“策略子进程静态观测缓存（减少 80% JSON 解析）”把吞吐推向 `50–60+ steps/s`。
